404	Возможности Netdata Cloud
405	Главная
406	Главная страница Netdata Cloud наглядно сводит воедино важную информацию: узлы, сбор и хранение данных, оповещения, пользователей и панели
407	Вид узла
408	Вид отдельного узла, которым вы пользуетесь сейчас, есть и в Netdata Cloud. Причём графики и визуализация там гибче и мощнее, чем в агенте.
409	В Netdata Cloud есть также функция Metric Correlations: она быстро находит метрики и графики, связанные с выбранным интервалом. Показывая стандартную панель только с относящимися к интервалу графиками, она помогает быстрее найти первопричину.
410	Обзор
411	Вкладка «Обзор» — удобный способ следить за инфраструктурой в Netdata Cloud. Внешне она похожа на локальную панель агента, но использует составные графики, показывающие агрегированные метрики всех узлов War Room (или выбранных) в реальном времени.
412	Составные графики «Обзора» показывают всю инфраструктуру на одном экране: можно заметить тренды или аномалии, затем сгруппировать метрики по узлам и перейти к панели узла для поиска первопричины.
413	Пример составного графика: пропускная способность дисков 5 разных узлов.
414	Узлы
415	Вид «Узлы» в Netdata Cloud позволяет смотреть и настраивать ключевые метрики любого числа узлов и переходить к панели любого узла для детального разбора проблем и аномалий.
416	Панели
417	В Netdata Cloud можно строить свои панели под нужды вашей инфраструктуры: ключевые метрики любой распределённой системы в одном месте, обзор с высоты птичьего полёта.
418	Оповещения
419	Вид «Оповещения» даёт общую картину доступности и производительности каждого узла в Netdata Cloud и позволяет из отдельного оповещения перейти к корреляции метрик или дальнейшей диагностике.
420	Аномалии
421	Вид «Аномалии» в Netdata Cloud быстро находит потенциально аномальные метрики и графики для выбранного интервала с помощью советника аномалий. Аномалии выявляются машинным обучением без учителя для каждой метрики прямо на узле!
422	Цены
423	Распределённая архитектура Netdata Cloud — обработка на самих узлах — позволяет добавлять пользователей почти бесплатно. Вместе с будущими платными планами для корпоративных клиентов это значит, что текущие функции всегда останутся бесплатными.
424	Конфиденциальность
425	Конфиденциальность данных очень важна для нас. Мы уверены: ваши данные принадлежат вам. Поэтому Netdata Cloud не хранит никаких метрик.
426	Основа Netdata Cloud — локально установленный Netdata Agent. Всё, что вы видите в браузере при работе с Netdata Cloud, передаётся напрямую от агента в панель Netdata Cloud. Данные проходят через наши системы, но не хранятся. Подробнее —
427	безопасная архитектура агента
